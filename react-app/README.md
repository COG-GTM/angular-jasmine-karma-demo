# react-app

React + TypeScript + Vite port of the Angular `angular-jasmine-karma-demo` app (shop items and users).

```bash
cd react-app
npm ci
npm run dev        # http://localhost:5173
npm test           # Vitest + React Testing Library
npm run e2e        # Playwright (run `npx playwright install chromium` once)
```

Stack, commands, folder layout, the component contract, ownership map and known traps are in
[MIGRATION.md](./MIGRATION.md).
